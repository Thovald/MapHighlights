<h2>Map Highlights</h2>

A customizable AddOn to highlight certain icons on the World Map.<br>
- Esc => "Options" => "Addons" => "Map Highlights"
- /maphl
- /maphighlights

Highlighted icons include <b>Waypoints, Instance Portals, Zone Portals, Delves, Flightmasters</b> and more.  
Highlights the <b>Player Location Arrow</b> as well.  
  
Some icons play an animation when opening the map, which can be repeated by clicking anywhere on the map.

Each icon has its own set of options to toggle or customize things like:
- Size
- Type of highlight
- Text
- Animation
